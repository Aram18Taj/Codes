# Codes
## Efeito Carga-Massa
### ⚛️ Simulador: Determinação da Constante e/m

Este repositório contém um simulador interativo em Python para visualizar e realizar o experimento para determinação da razão carga-massa do elétron ($e/m$).

O simulador utiliza a força de Lorentz em um campo magnético gerado por Bobinas de Helmholtz para curvar um feixe de elétrons, permitindo que o usuário tire medidas virtuais e compare seus resultados com a literatura.

### 🚀 Baixar e Executar

Você pode baixar o script do simulador diretamente clicando no botão abaixo:

[![Baixar Simulador](https://img.shields.io/badge/Baixar-Simulador.py-2ea44f?style=for-the-badge&logo=python&logoColor=white)](https://raw.githubusercontent.com/Aram18Taj/Codes/main/Simulador.py)

#### Pré-requisitos
Para rodar o simulador no seu computador, você precisará ter o Python instalado e as seguintes bibliotecas:
- `numpy`
- `matplotlib`

Você pode instalá-las rodando o comando abaixo no terminal ou prompt de comando:
```bash
pip install numpy matplotlib
```
